# TopN 历史基线与对照边界

本文件保留既有报告的历史结果，**不是当前合成指标流程的基线**。原准确度结果来自真实业务集群采样和旧 API；当前流程使用 09 注入 store，并可用 32/33 测试 visualization 视图。数据来源、实体、窗口和 API 均可能不同，不能把两者的分数直接对比，也不能据此推断升级收益。当前尚无经本次修改验证的新流程结果。

## 当前流程如何记录

按 [操作卡](../repro/README.md) 在隔离测试环境启动 Console + store，使用 `09` 的 fill / stream 注入 index 和 node 指标，再按需 resample 和运行 32/33。记录版本、配置、数据画像、tag、cluster 标签、时间范围、采样间隔、查询参数、具体接口、权限及报告路径；仅在条件和被测对象可比时对照新的后续轮次。

- `32` / `33` 是 visualization 视图查询，不是 advanced TopN 验证，也不保证 UI 或选择器可用。
- `30` / `31` 是保留的 advanced API 验证，需要真实或测试 cluster metadata、权限及 agentless 等条件，还需要兼容的采样；单靠注入标签不够。
- `09 resample` 与被测数据同源，不是独立真值；`expected` 是共享注入器假设的解析式期望，不能替代独立验证。
- `34` 的旧 API probe 同样需要 cluster metadata；`35`–`37` 的安全与结果可靠性待复核，不应作为可靠基线或执行建议。
